# Data

The project uses the publicly available **Honda Data** dataset published on Kaggle by `omartorres25`.

Source: https://www.kaggle.com/datasets/omartorres25/honda-data

The original CSV is not currently redistributed in this repository because its current redistribution terms have not been verified. The source data also contains fields such as VIN and Stock Number that should not be published unnecessarily.

If the dataset is later included, confirm its current licence / redistribution terms first and use a publication-safe version of the data.
